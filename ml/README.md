# ml

Offline scripts: data download, index build, gallery build and evaluation.

- `scripts/` — runnable scripts (first ones arrive in Phase 1).
- `data/` — downloaded source data. Gitignored.
- `artifacts/` — built index and converted models. Gitignored.
- `eval/` — eval-set builders and reports. Reports in `eval/reports/` are committed as markdown.
